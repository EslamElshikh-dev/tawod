أسئلة شائعة

أسئلة قبل اتخاذ القرار

إجابات مختصرة توجهك إلى الدليل أو الخدمة المناسبة دون تكرار المحتوى.

لا؛ يجب ربط البنود بالمخططات والمواصفات والفحوصات والمسؤوليات المطلوبة للمشروع.

تختلف المسؤوليات حسب نوع المشروع والعقد والجهات المختصة، لذلك يجب تثبيتها في مستندات المشروع.

لأن كثيرًا من العناصر تصبح غير مرئية بعد الصب أو اللياسة أو تركيب الأسقف والتشطيبات.
