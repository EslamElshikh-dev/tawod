## طريقة التشغيل محليًا

يتطلب المشروع Node.js 20.9 أو أحدث.

### تثبيت الحزم وتشغيل بيئة التطوير

```bash
npm ci
npm run dev
```

### إنشاء نسخة الإنتاج

```bash
npm run build
```

ينشئ الأمر مجلد `out/`، ثم يتحقق آليًا من التطابق الحرفي لجميع صفحات HTML وعددها 176 صفحة ومن وجود الأصول الأساسية.

## النشر على GitHub Pages

المشروع مناسب للنشر على Vercel أو GitHub Pages من مجلد `out/`.

### خطوات مقترحة

1. شغّل `npm ci`.
2. شغّل `npm run build`.
3. ارفع محتويات مجلد `out/`، ويتضمن ملف `CNAME` بالقيمة:

```text
tawodco.com
```

4. سير العمل `.github/workflows/deploy-pages.yml` ينفذ هذه الخطوات تلقائيًا بعد الدمج المعتمد في `main`.
5. بعد النشر، اختبر الموقع والروابط وملف السايت ماب.

## استراتيجية الانتقال إلى Next.js

- ملفات HTML الحالية هي مصدر المحتوى المعتمد في هذه المرحلة.
- Route Handlers ثابتة تولّد المسارات أثناء البناء عبر `generateStaticParams`.
- الأصول تُجهز في `public/` وقت البناء فقط، لذلك لا توجد نسخ مكررة داخل Git.
- اختبار `verify-next-export.mjs` يمنع اعتماد أي بناء يغيّر الصفحة أو يفقد مسارًا.
- يمكن لاحقًا تحويل الصفحات إلى React Components تدريجيًا، صفحة أو مجموعة صفحات في كل مرة، دون تغيير الروابط الحالية.

## متابعة الفرص داخل لوحة الإدارة

- مركز المتابعات يعرض الفرص المفتوحة من **جميع التواريخ**، مع فلاتر التأخير، المستحق اليوم، غياب المسؤول أو الموعد، وغياب التواصل منذ 7 أيام. المواعيد تُدخل وتُعرض بتوقيت الرياض مهما كان توقيت جهاز المستخدم.
- مؤشرات المبيعات تخص الفرص التي **بدأت إحالتها في الفترة المختارة** وحالتها الحالية، وليست العقود الموقّعة داخل الفترة. بيانات الاختبار مستبعدة من المؤشرات والمتابعات والتصدير. حدود العرض 500 فرصة لا تقلص إجماليات قاعدة البيانات.
- اعتماد التأهيل يحتاج خدمة مناسبة وتواصلًا تمت مراجعته. الفرصة المؤهلة المفتوحة تحتاج مسؤولًا، إجراءً وموعد متابعة. العقد يحتاج قيمة موجبة، وفقد الفرصة يحتاج سببًا. أسماء العملاء وأرقامهم ونصوص الرسائل لا تُدخل في اللوحة.
- النقل من سجل الإحالات يرتبط بمعرّف الحدث الكامل؛ تفتح الإحالة المسجلة فرصتها الموجودة بدل إنشاء نسخة. المصدر والحملة وصفحة الدخول تُؤخذ من الحدث المقاس. الفرصة اليدوية تُعرض بوضوح كمصدر غير مرتبط.
- يسجل `tawod_sales_history` إنشاء الفرصة وتغير المرحلة وبيانات التشغيل من تاريخ تفعيل التحديث. لا تُخترع تواريخ للمراحل السابقة. إقرار Google Sheets لا يُحسب نشاط مبيعات. حفظ تعديل متعارض يُرفض مع إمكانية تحميل النسخة الأحدث.
- قاعدة البيانات الجديدة خاصة بـ`service_role` خلف جلسة الإدارة الموقّعة؛ المسؤول داخل الفرصة حقل تشغيلي ولا يمنح صلاحيات مستخدم مستقلة.

تُطبق migration `20260930014446_tawod_sales_followup_workspace.sql` أولًا، ثم تُنشر وظيفة `tawod-analytics`، ثم واجهة اللوحة. اختبار `npm run test:sales-workspace` يشغّل migration وطلبات الوظيفة على Postgres محلي معزول باستخدام PGlite، دون قراءة بيانات الإنتاج أو إرسال تحويلات إعلانية.

## النتائج التجارية والقرارات

- لوحة المراحل تعرض **كل الفرص المفتوحة** أو **فرص فترة الإحالة**. الأعداد والقيم تُحسب على كامل البيانات الفعلية، وتُعرض حتى 40 بطاقة لكل مرحلة مع توضيح الحد. بقاء الفرصة في المرحلة 14 يومًا إشارة للمراجعة، وليس إثباتًا لتوقف التواصل.
- «عقود اعتُمدت في الفترة» تخص الفرص التي حالتها الحالية عقد موقّع وآخر اعتماد لهذه المرحلة مسجل خلال الفترة، مهما كان تاريخ إحالتها. إعادة فتح الفرصة تُخرجها من نتائج الإغلاق الحالية. تاريخ الاعتماد في اللوحة ليس بالضرورة يوم توقيع العقد الفعلي؛ النتائج القديمة دون تاريخ معروف مستبعدة ومعلنة.
- تحليل المصادر والحملات يخص فرص فترة الإحالة وحالتها الحالية. المصدر إحالة التواصل المقاسة المرتبطة بالفرصة، وليس إسنادًا متعدد اللمسات. القيم هي قيمة تعاقد حالية أو توقع للفرص المفتوحة؛ لا تمثل تحصيلًا أو ربحًا أو ROAS. حجم العينة الصغيرة ظاهر مع النسب. أسباب عدم التعاقد تشمل الأسباب غير المسجلة بوضوح.
- مركز القرارات يحفظ إجراءات الفريق عبر جميع التواريخ. اعتماد اقتراح يفتح محررًا للمراجعة قبل الحفظ، ويرتبط مفتاح الاقتراح بإجراء واحد قابل لإعادة الفتح. دليل الإنشاء ومصدره وفترته ثابتة؛ التوصيات الحالية أو تغيير فترة التقرير لا تغلق الإجراء تلقائيًا.
- بدء التنفيذ يحتاج مسؤولًا وموعدًا. إغلاق الإجراء يحتاج نتيجة أو سبب استبعاد، والتنفيذ المكتمل يحتاج مسؤولًا. التغييرات محفوظة في `tawod_decision_history`. التعديلات المتعارضة مرفوضة دون مسح مدخلات المستخدم، مع تحميل أحدث نسخة بإجراء واضح. أسماء المسؤولين حقول تشغيلية ضمن جلسة الإدارة الحالية، وليست حسابات بصلاحيات مستقلة.
- التصدير التجاري يحافظ على تعريف المجموعة والفترة، ويشمل المصادر أو أكبر 100 مجموعة حملة عند تجاوز الحد. CSV عربي وUTF-8 مع حماية صيغ الجداول. الملخص المنسوخ يميز بين مجموعة الإحالات ونتائج اعتماد العقود.

ترتيب النشر: migration `20260930024439_tawod_decisions_commercial_workspace.sql`، ثم وظيفة `tawod-analytics`، ثم الواجهة. كل جداول وRPCs القرارات والتحليل خاصة بـ`service_role` مع RLS ومنع `anon` و`authenticated`. يغطي `npm run test:sales-workspace` السيناريوهات الفعلية على Postgres معزول دون كتابة بيانات إنتاج تجريبية.
